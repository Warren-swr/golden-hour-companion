# 核验说明

## 已交付影片

v10 正式 MP4 与 1080 预览均已完整解码，确认 59 秒、24 fps、1416 帧、无音轨。播放器完整显示 3 秒，之后展开并连续播放原片前 60 帧。展开与原片部分没有检测到重复帧、意外黑帧或异常镜内跳变。

视觉复查覆盖六页总览中的 143 个抽帧、全部切点、片尾，以及字体和播放图标原尺寸细节。检查方式为抽帧视觉审查与连续性测量；不将完整解码表述为人工实时看完影片。

- [停留与展开时序](validation/opening-v10.json)

## 公开仓库

公开版本保留源码来源索引，并检查 Git 跟踪文件的大小、符号链接、私有配置路径、凭据模式和 Python 语法。场景发布包已检查为相对资源路径、12 张嵌入贴图、无外链库和无嵌入文本脚本。

`tools/check_public_tree.py` 用于发布前检查；GitHub Actions 运行同一检查。它是静态源码检查，不替代完整 Blender 渲染或视频视觉评审。

新渲染入口已使用 Blender 4.5.12 LTS 在 CPU 上实际渲染第 1 帧（128 × 128、1 sample）。新编码入口已从四张测试帧导出正式 MP4 与预览，确认帧数、无音轨、没有 ProRes 输出，并验证拒绝覆盖和缺帧检查。该测试验证入口可用，不代表重新渲染完整成片。见 [工具试运行记录](validation/tools-smoke.json)。

待发布附件的字节数和 SHA-256 记录在 [release-assets.json](release-assets.json)。对应影片与场景目前尚未作为公开 Release 附件发布。
